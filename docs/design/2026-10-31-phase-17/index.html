Phase 17: the outbox (mockup)

Five small choices. Each has A, B, C (or A, B). The ★ is my recommendation. Change the theme and language at the top, tap the state buttons to see each option in each situation. The Macedonian words are drafts, not approved.

1 · How a "not synced yet" item looks in a list

The same three rows in each option: one saved, one still waiting, one saved. Pick the screen to see the option on it.

2 · Where the "waiting" count and "All up to date ✓" live

Pick a situation, then look at the three phones.

The failed-item sheet is the same in A, B and C: it opens when you tap the failed message (or the Settings line in C).

3 · What waiting money does to balances and totals

Example: Marko owes you 500 MKD. You saved a new 300 MKD expense while the server was asleep, and it is still waiting.

4 · The euro price of a waiting EUR item

A · The server sets it when it saves ★

Same as today. The waiting row says "Euro price set when sent" (turn on the checkbox in part 1 to see it). Nothing for you to do.

B · The phone looks it up now

Needs the phone to know today's price while the server sleeps, so it would be a guess that could differ from what the server saves. Not possible without a new feature.

5 · A failed item and the queue behind it

A · The rest keeps going ★

1. Coffee 200 MKD saved
2. Dinner 1,200 MKD in "Ohrid trip" refused: you left that group
3. Taxi 300 MKD saved

Items don't depend on each other, so one problem doesn't hold up the others. The failed one stays with Retry / Discard.

B · Everything stops at the failed one

1. Coffee 200 MKD saved
2. Dinner 1,200 MKD refused
3. Taxi 300 MKD waiting…

Safer if items depended on each other, but they don't, and one old problem would block everything new until you deal with it.
